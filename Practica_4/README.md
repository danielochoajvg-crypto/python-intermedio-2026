# Práctica 4 - Sistema bancario POO

Ejercicio de Python sobre programación orientada a objetos.

## Archivos

- `codigoprueba.py`: prueba de las cuentas bancarias.
- `tarea/cuentabancaria.py`: clase base CuentaBancaria.
- `tarea/cuentaahorro.py`: cuenta de ahorro.
- `tarea/cuentacorriente.py`: cuenta corriente.
- `tarea/cuentacheque.py`: cuenta cheque.
- `tarea/__init__.py`: archivo del módulo.

## Ejecutar

Desde esta carpeta, ejecutar:

`python3 codigoprueba.py`
